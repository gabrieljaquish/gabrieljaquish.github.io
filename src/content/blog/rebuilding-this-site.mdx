The previous version of this site was built by hand years ago. This one is generated by
[Astro](https://astro.build) from Markdown files, built in GitHub Actions, and served as
plain static files from GitHub Pages behind Cloudflare.

## Why static

There's no server-side code, database, or admin login to attack: every page is just
a file. The few interactive pieces are small React components that only load on the pages
that use them, like this one:

<HardeningChecklist client:visible />

## A strict Content-Security-Policy

Every page carries a CSP that allows only this site's own scripts and styles, identified
by hash:

```text
default-src 'none'; script-src 'self' 'sha256-…'; style-src 'self' 'sha256-…'
```

If something manages to inject a script, the browser refuses to run it.
